🌻 Mina Mini Games - Countryside Arcade

Welcome to Mina Mini Games, a cozy, kid-friendly browser game platform set in a sunny countryside meadow! This collection features fun, educational interactive mini-games built with modern web technologies that run instantly in any web browser without needing any installation or backend servers.

🎮 Included Mini-Games

1. 🧺 Mina Market (Chinese Character Merging Game)

File: mina-market.html

Description: A fun and educational puzzle-merging game set in a vibrant village grocery store! Players merge matching Chinese characters and components to form compound characters, unlock new vocabulary, stock market shelves, and help friendly customers.

Key Features:

Interactive Chinese character merging mechanics.

Kid-friendly learning curve with visual cues.

Bright market shop themed visuals.

2. 🦁 Sounds of the Wild (Animal Sound & Voice Studio)

File: animal-sounds.html

Description: An interactive sound directory and studio where kids can learn animal calls, record their own funny animal voice imitations (like making a "Moo!" sound for a cow), apply audio FX, and play a sound guessing quiz!

Key Features:

Realistic Web Audio procedural sound synthesis.

In-browser voice recorder studio with funny FX filters (Chipmunk, Monster, Echo).

Persistent Local Storage: Audio recordings are saved locally to your device using IndexedDB, so your voices stay saved even when refreshing or re-opening the site.

Interactive Animal Sound Quiz Game.
